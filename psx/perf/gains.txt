# Lever-gain table of docs/psx-perf-levers.md (plan 20, step 12): the one
# input of the per-frame estimate besides the judge table
# (psx/perf/full-run-frames.txt) and the step 9 spike frames
# (psx/perf/spike-frames.txt). Part of the report, deleted with it.
#
# Rows, whitespace-separated; a "#" that starts a word comments out the rest
# of the line (a "#" inside a path, as in ui_send_to_hovered#1, does not):
#   budget <hblanks>
#   range <name> <first>-<last>
#   class <label> <spikes path>
#   override <frame> <path> <share%>
#   ratio <default|class label> <child>=<rho>[,...]
#   lever <id> <measured|estimated> <draw|update|submit> <work|per-call|scale> <group>/<alt> <scope> <gain%|abs:<hblanks>>
#   spread <id> <kind> <class label|*> responsible|responsible+save:<share%>
#   cap <draw|update|submit> <work|per-call|scale> <scope> <max%>
# Scopes: all, in-game (every frame outside the ranges), in-game@<run> (the
# same, only when tools/lever_estimate.sh runs with run=<run>), ordinary (not
# a spike frame), class:<label>, class:*, range:<name>; for one lever on one
# frame and part the most specific scope wins: range > class:<label> >
# class:* > ordinary > in-game@<run> > in-game > all.
# A gain% is relative to its part on that frame.
#
# Composition, per frame and part: inside a layer, rows summed within an
# alt, the largest alt of a group taken, groups summed, capped at 100;
# across layers part' = part x (1 - work)(1 - per-call)(1 - scale), rounded
# half up. The measured end reads measured rows only, the estimated end
# every row. Spreading is a permission, allowed in both ends.
#
# Draw rows: window bound or measured delta / the run's window draw (probe
# baseline: start 465, draw-5564 19491, draw-6000 13987; per-frame bounds
# over 465, 1299.4 and 932.5). range:title and range:start take the start
# run; in game, each lever has one in-game@draw-5564 and one
# in-game@draw-6000 row, so an estimate runs once per draw run with that
# run's whole lever set (run=draw-5564, run=draw-6000), the less favourable
# run being the headline; never a per-lever minimum across the runs.
#
# Two decisions from chunk 2's verification (report, checklist items 14-15):
# - Strict spike-frame rule (tool default, spike-rule=strict): a spike frame
#   is within budget only if its spread work is placed AND its own leftover
#   (update - spread work + draw' + submit') is at most 263. Step 9's rule
#   (placed is enough) is spike-rule=step9, used only by
#   make lever-estimate-check; by leftover it left 109 of the 165 frames it
#   called fitting above 263 (max 922, frame 5719).
# - Cap rows: the composed draw work layer of a run may not exceed
#   (run draw - the tree's measured costs no lever removes) / run draw; the
#   derivation sits above the cap rows below.
