1. **La profondeur de chaîne elle-même n'exerce rien de structurellement nouveau** : `pico8_instance_get_field` (`pico8_class.c`) est une simple boucle `for (cls = inst->cls; cls != NULL; cls = cls->parent)` — totalement agnostique à la profondeur, déjà exercée avec succès à 5 niveaux réels par la Partie 1 de la vérification jetable ci-dessus. Rien dans son propre code ne distingue une chaîne à 2 niveaux (déjà couverte par `test_real_ke_subclass_with_own_distinct_pq`, Chunk 4) d'une chaîne à 5 niveaux — un changement de DONNÉES (combien de maillons), pas de MÉCANISME, exactement le raisonnement déjà appliqué par tous les sous-lots du Chunk 13/14 à chaque question similaire.
2. **La largeur de la famille (cv/cg à travers des classes sœurs/cousines) n'exerce rien de structurellement nouveau non plus** : `pico8_lt`'s propre boucle `for p in all(bm) do if (e[p]) ft(cv,p,e) end` (présence de champ, pas profondeur) et `for t in all(e.nu) do ft(cg,t,e) end` (parcours de liste, y compris une liste VIDE pour `ga`) sont toutes deux déjà exercées, individuellement, par chaque chunk précédent — ce chunk ajoute PLUS de classes utilisant ces MÊMES boucles simultanément, pas une nouvelle forme de boucle. Le cas `ga.nu=o()` (liste vide, donc AUCUN enregistrement `cg`) est un cas de données (liste de longueur 0), pas un nouveau chemin de code dans `pico8_lt` — confirmé par relecture directe de son implémentation.
3. **Le vrai risque de régression de ce chunk n'était PAS dans le mécanisme générique** (`kv:jr`/`hv`/`cv`/`cg`/`dc`/`mv`/`lt`/`he`, tous inchangés, zéro ligne touchée dans `pico8_entity.c`/`pico8_class.c` par ce chunk) **mais dans du DONNÉES/logique de classe déjà livrée** (`pico8_jo_pq`'s propre lecture de `gb`) — trouvé et corrigé, voir plus haut. C'est exactement le type de découverte qu'un test de fumée générique (avec des classes factices) n'aurait jamais pu attraper, puisqu'elle dépend de VRAIES specs de classe (`hp=1..6`) et de VRAIES données cart (`gb` réel) — seul un programme d'intégration bout-en-bout avec de vraies classes (comme la vérification jetable ci-dessus) pouvait la révéler.
