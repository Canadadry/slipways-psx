# Project notes

- Never try to run the project (e.g. `love game`, `make run`). It's a GUI app; don't launch it. Use `make test` to verify changes instead.
- The porting target is PSX (`PSn00bSDK`), not GBA — see `docs/plan.md`. There is no headless test-loop tooling for it yet (Phase 0 of the plan); the former GBA devkit/`mcp-mgba` tooling has been removed as obsolete.
- `psx-hello/` is a PSn00bSDK smoke-test project, and it's fully working: `make psn00bsdk-toolchain-setup` builds the real toolchain (slow, ~30-45 min, network-heavy — do not run it expecting it to finish quickly); `make psx-hello` builds `psx-hello.exe` and a bootable CD image; `make psx-hello-boot-test` boots it under Mednafen (`Xvfb`+`xdotool`, apt-installed) and was screenshot-verified end to end — pad text renders, Cross/D-pad/Circle all work as designed — given a real Sony BIOS dropped in `~/.mednafen/firmware/` by whoever's testing (never committed or distributed from this repo; `make psx-hello-openbios-setup` builds a legal open-source BIOS replacement instead, but it currently can't get far enough to boot this disc — a precisely-diagnosed upstream OpenBIOS bug, not a gap in this repo). See `docs/psx-hello-world.md` for the full story, including the PS-EXE stack-pointer fix that made booting work at all and why an earlier session wrongly assumed the toolchain build and any emulator were unreachable.
