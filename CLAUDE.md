# Project notes

- Never try to run the project (e.g. `love game`, `make run`). It's a GUI app; don't launch it. Use `make test` to verify changes instead.
- The porting target is PSX (`PSn00bSDK`), not GBA — see `docs/plan.md`. Phase 0's headless test harness tool is decided (PCSX-Redux, `make pcsx-redux-setup` — build and boot validated, the MCP/agent bridge on top is still to build); the former GBA devkit/`mcp-mgba` tooling has been removed as obsolete.
- `psx-hello/` is a PSn00bSDK smoke-test project, and it's fully working, two independent ways: `make psn00bsdk-toolchain-setup` builds the real toolchain (slow, ~30-45 min, network-heavy — do not run it expecting it to finish quickly); `make psx-hello` builds `psx-hello.exe` and a bootable CD image; `make pcsx-redux-setup` + `make psx-hello-boot-test-pcsx` builds PCSX-Redux and OpenBIOS from source and boots it — fully legal, no real BIOS needed, and it just works (this is also the tool `docs/plan.md` Phase 0 settled on). `make psx-hello-boot-test` boots it under Mednafen instead (`Xvfb`+`xdotool`, apt-installed) and was screenshot-verified end to end — pad text renders, Cross/D-pad/Circle all work as designed — but needs a real Sony BIOS dropped in `~/.mednafen/firmware/` by whoever's testing (never committed or distributed from this repo); OpenBIOS under Mednafen specifically still hits a real upstream bug (not under PCSX-Redux). See `docs/psx-hello-world.md` for the full story.
