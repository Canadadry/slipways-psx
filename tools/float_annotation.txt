# Annotation des casts (int)pico8_fixed_to_double(...) du coeur, lue par
# tools/float_inventory.sh. Le seul des rapports flottants qu'on edite a la main.
#
# Une ligne par cast : fichier | fonction | extrait | occurrence | population | etape | justification
#   cle          fichier, fonction, extrait tel que l'inventaire l'imprime, et
#                occurrence (1, 2...) parmi les casts de meme extrait dans la
#                fonction ; jamais le rang, qui glisse des qu'un frere est converti
#   population   (a), (b), (c) ou a auditer
#   etape        (b) -> C1, (c) -> D1, (a) -> C1 si le signe >= 0 est prouve,
#                sinon D1, a auditer -> -
#   justification une ligne non vide, jamais recopiee dans l'inventaire.
#                (a) : un renvoi lua.lua:<ligne>, et chaque ligne citee de
#                pico8/lua.lua contient flr( ; (b) : la preuve de signe ;
#                (c) : pourquoi ; a auditer : ce qui manque
#
# Un cast dans une aide pico8_*_to_int prend la pire population de ses appelants.
# Une observation "jamais negatif sur le filet" est un indice, jamais une
# preuve : une justification (b) peut la citer en complement, pas a sa place.
#
# Une annotation sans cast, un cast sans annotation, un (a) non source ou une
# etape contraire a la population arretent l'inventaire, donc make test.
